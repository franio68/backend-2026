## GitHub

### ¿Qué es y para qué sirve?

- Es un sistema de Control de Versiones en la nube
- Sirve como copia de seguridad de nuestro repositorio local
- Puede conectar automáticamente con nuestro servicio de alojamiento de apps en la nube
  > Aparte: 99% - 99,9% - 99,99%
- Trabajo en equipo
- Punto de encuentro de la comunidad Open Source (proyectos colaborativos de código abierto)
